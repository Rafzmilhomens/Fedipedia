# Multiplataforma

`Mul·ti·pla·ta·for·ma`

_adjetivo · conceito_

1. As redes federadas são multiplataforma, o que significa que há vários tipos de "mídias sociais" que se comunicam pela mesma linguagem. Ou seja, é necessário somente uma única conta para acessar qualquer plataforma.
