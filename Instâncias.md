# Instâncias

`Ins·tân·cias`

_substantivo feminino · conceito_

1. São basicamente os servidores que possibilitam a existência de cada conta. Cada servidor funciona como uma "unidade da federação" do fediverso. E, tal como os brasileiros de diferentes estados, os usuários podem comunicar-se com toda a rede federada a partir de sua instância.
